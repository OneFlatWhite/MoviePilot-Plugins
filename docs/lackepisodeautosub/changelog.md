# ⑥ 版本历史

[← 返回首页](README.md)

## v1.9.1（2026-09-20）

- **修复详情页表格不显示**：部分 MP 前端版本（如 v2.15.6）不渲染 VDataTable 的行，
  三个表（补齐验证/疑似死任务/最近历史）全部改为原生 HTML 表格，渠道列带彩色标签；
- 运维侧：插件仓库与发布版对齐（修掉"市场同步把新版拉回旧版"的降级链）。

## v1.9.0（2026-09-19）

- **爱影 API 按缺集精确选包**：解析资源覆盖集数（S01E06-S01E10/单集/S1-S5/全集），
  无关包直接淘汰，贪心集合覆盖，平局时 115 分享链接优先→溢出小优先→体积小优先；
  选包理由写入渠道详情；
- **部分季失败不再漏盯**：成功的季立即进验证快照，下轮补订成功自动合并；
- **即时搜索前探 Emby 就绪**（5 分钟缓存）：Emby 未就绪不触发，杜绝"误判整季缺失拖整季包"；
- 测试钩子 `ay_api_test` 新增 `eps` 参数（模拟缺集验证选包）。

## v1.8.1（2026-09-19）

- **「你已经转存过该文件」按成功处理**（内容已在 115，不再误转 PT 重复下载）；
  打包回执按行分析，只有「分享已取消」等真实失败才转 PT；
- **即时搜索改异步线程触发**：之前同步触发每部卡 1~13 分钟，扫描速度翻倍。

## v1.8.0（2026-09-19）

- **SA 转存直连 HTTP**（企业微信回调协议，SA 消息接口唯一受理形态）：
  不再需要 TG 机器人发链接，TG 从必需降级为可选兜底；
- 新配置：`sa_http_*` 七项（地址/Token/AESKey/CorpID/UserID/AgentID/开关）；
- 新联调 API：`GET /sa_http_test`。

## v1.7.0（2026-09-19）

- **爱影查询改 HTTP API 主通道**（api.ayclub.vip:5050，按 TMDB ID 精确查）：
  额度约 6500 次/月（TG 机器人 ~600 的 10 倍），且能搜到 TG 流程漏掉的资源；
  TG 点击流保留为兜底；
- **渠道详情记录**：历史条目带 `channel`（PT/爱影API/爱影TG/混合）+ 人话明细，
  汇总通知加渠道前缀；页面新增「爱影 API 剩余次数」卡；
- 新配置：`aiying_api_*` 五项；新联调 API：`GET /ay_api_test`。

## v1.6.0（2026-09-19）

- **增量扫描（完结账本）**：TMDB 已完结且无缺集的剧记账后直接跳过，
  日常一轮从 ~70 分钟缩到几分钟；每周日全量兜底；完结剧出新季/删集自动移出账本（自愈）；
- 新配置：增量扫描 / 每周全量扫描日 / 本轮强制全量扫描。

## v1.5.0（2026-09-19）

- **订阅后立即搜索**（默认开）：建的订阅立刻触发 MP 搜索，不再干等周期任务
  （周期任务每个订阅随机休眠 60~300 秒）；
- **修复部分季订阅失败整部剧被销账**的严重 bug：全部季成功才销账，失败季下轮自动重试；
- **验证回环闭环**：超时自动重置订阅（默认开）/ 订阅丢失自动补订（默认关）；
- 验证回环独立超时预算（不再与扫描互相挤占）；「立即停止」真正生效；
- 页面修正：累计缺集口径标注、超时状态实时计算、静态快照提示。
