# 缺集自动补齐（LackEpisodeAutoSub）使用 Wiki

> 一个 MoviePilot V2 插件：自动找出你 Emby 里缺集的电视剧，每天限量帮你补齐——
> **115 网盘有资源就直接转存（不下载），没有就走 PT 站下载兜底**，
> 最后自动刮削生成 STRM，Emby 里直接能看。订完还盯着它到底入没入库，闭环。

**当前版本：v1.9.1** · 作者：OneFlatWhite · [插件源码](../../plugins.v2/lackepisodeautosub/__init__.py)

---

## 它每天替你干什么（一图流）

```
每天凌晨 4:17（可调）自动跑一轮
  │
  ① 入库验证：昨天订的剧，Emby 里真到了吗？
  │     ├─ 到了 → 核销 ✅；115 补齐的顺手退掉 PT 订阅
  │     └─ 超 7 天没到 → 告警 + 自动重置订阅让 MP 重搜
  ② qb 死任务检测（0 进度挂着不动的，提醒/删除）
  ③ 磁盘空间检查
  ④ 增量扫描 Emby 剧集库（已完结已补齐的直接跳过，几分钟完事）
  │
  ▼ 每部缺集剧 —— 先 115，后 PT：
┌──────────────────────────────────────────────┐
│ A. 爱影 API 查 115 资源（按 TMDB ID 精确找）    │
│    ├─ 有 → 按你缺的集精确选包 → SA 离线转存 115 │
│    │        （全程 HTTP，不经过你的 NAS 下载）    │
│    └─ 没有 → 走 B                              │
│ B. PT 兜底：逐季建 MP 订阅 → 立即搜索           │
│    → 四个 PT 站搜种 → qBittorrent 下载          │
│    → MP 整理改名 → 上传 115 → 删本地            │
└──────────────────────────────────────────────┘
  ▼ 两路汇合：Symedia 归档刮削 + STRM → Emby 可播
  ▼ 明天 4:17 回到 ① 验证这一轮（闭环）
```

## 两条通道，互为备份

| 通道 | 资源来源 | 经过本地下载？ | 适合 |
|---|---|---|---|
| **115 通道**（爱影 API） | 115 网盘分享/离线 | ❌ 云端直达 | 有 115 会员，热门剧基本都有 |
| **PT 兜底** | 天空/馒头/人人/憨憨等 PT 站 | ✅ 过一遍（传完即删） | 115 没有的冷门资源 |

插件自动优先 115、静默回退 PT，最后还有 TG 机器人查询做第三重兜底（可选，见通道篇）。

## 30 秒极速上手（已有完整环境的人）

1. 把 `lackepisodeautosub` 文件夹放进 MP 容器 `/app/app/plugins/` 并重启 MP；
2. MP → 设定 → 媒体服务器，配好 Emby（地址 + API Key）；
3. MP → 设定 → 下载器/站点，配好 qBittorrent 和至少一个 PT 站；
4. 插件设置里：开「调试模式」先空跑一轮，确认缺集识别没问题；
5. 关调试、开启用，填爱影 API Token 和 SA 参数（见[通道篇](channels.md)）；
6. 每天凌晨自动干活，你只看通知。

> ⚠️ 新手请一定按 [① 安装准备与安装](install.md) 一步一步来，跳过检查清单会踩坑。
