## 一、开工前准备清单（逐条打勾）

| # | 条件 | 怎么检查 | 没有怎么办 |
|---|---|---|---|
| 1 | **MoviePilot V2 正常运行** | 浏览器能打开 MP 网页并登录 | 先装 MP（jxxghp/moviepilot-v2） |
| 2 | **MP 已配 Emby 媒体服务器** | MP → 设定 → 媒体服务器，列表里有 Emby 且测试通过 | 见下方「Emby API Key」 |
| 3 | **MP 已配下载器和目录** | 设定 → 下载器有 qBittorrent 且连接正常；设定 → 目录有下载目录+媒体库目录 | 按 MP 官方文档配 |
| 4 | **至少一个 PT 站可用** | 设定 → 站点，测试通过 | 没有 PT 也能只用 115 通道（见通道篇） |
| 5 | **Emby 剧集库已刮削（有 TMDB ID）** | Emby 随便点部剧，详情页有 TMDB 链接 | 先在 Emby 刮削，否则插件大量跳过「无 TMDB ID」 |
| 6 | **MP 能手动订阅下载** | 手动订一部剧，能搜能下 | 链路不通先修 MP |
| 7 | （115 通道）**115 会员 + 爱影 API** | 见 [③ 通道配置](channels.md) | 没有则纯 PT 也能跑 |
| 8 | （115 通道）**SA（Symedia）在跑** | SA 网页能打开，115 登录态正常 | SA 负责把链接离线进 115 |

### Emby API Key 怎么拿

1. 打开 Emby → 右上角齿轮「管理服务器」→「高级」→「API 密钥」→「新建」
2. 名字随便填（如 `moviepilot`）→ 保存 → 复制密钥
3. MP → 设定 → 媒体服务器 → 添加 Emby：填地址（如 `http://192.168.x.x:8096`）+ 密钥 → 测试 → 保存

> 不配这步 = 插件不知道你库里有什么，会把已有的剧当缺的重复下载。

## 二、安装插件（3 分钟）

### 方法 A：插件市场（推荐）

MP → 插件 → 插件市场 → 添加仓库：

```
https://github.com/OneFlatWhite/MoviePilot-Plugins
```

刷新后搜「缺集自动补齐」→ 安装。

> ⚠️ **重要认知**：MP 启动时会按市场仓库同步插件文件。如果你手动改过插件源码，
> 又没把改动推回这个 GitHub 仓库，**重启后会被市场的旧版本覆盖**（真实踩过的坑）。

### 方法 B：手动放文件

把 `lackepisodeautosub` 文件夹（内含 `__init__.py` 和 `requirements.txt`）复制到
MP **容器内** `/app/app/plugins/lackepisodeautosub/`（注意不是 `/config/plugins/`）。

强烈建议挂载持久化，容器重建不丢：

```yaml
volumes:
  - /volume1/docker/moviepilot/plugins:/app/app/plugins
```

然后重启 MP 容器，插件列表里出现「缺集自动补齐」即成功。

## 三、首次使用流程（务必按顺序）

```
第 1 步：保持「调试模式」开启（默认开）——只扫描记录，不真订阅
第 2 步：勾「立即运行一次」→ 保存
第 3 步：去 MP 日志页搜「缺集自动补齐」，看扫描过程（库大要等几十分钟）
第 4 步：打开插件详情页：
   - 历史记录里结果列应该是「调试-待订阅」
   - 剧名、缺集数是否符合你的认知？
   - 不对 → 调「单部剧缺集数上限」「排除关键词」再跑
第 5 步：确认无误 → 关「调试模式」→ 开「启用插件」→ 保存
第 6 步：每天自动跑，看汇总通知即可
```

> **千万不要跳过调试直接正式跑。** 几千部缺集的库一旦识别有偏差，会瞬间挂满订阅。

## 四、配套环境建议（来自实战）

1. **固定 MP 的 SECRET_KEY**：MP 默认每次启动重新生成密钥，**所有人都会被强制登出**。
   在 compose 的 environment 加一行解决：
   ```yaml
   - SECRET_KEY=一段固定的长随机字符串
   ```
2. **Symedia 归档任务**：如果你用 Symedia 做刮削归档，确认它的归档任务
   **真的监控了你的卸货目录**（如 `我的接收`）——我们遇到过任务不存在导致
   几百 GB 堆积无人归档的事故。同时给每条任务配 `failed_dir`（识别失败隔离区），
   否则识别不了的文件会堵死归档队列。
3. **代理**：TMDB 在国外，MP 必须配代理（compose 里 `PROXY_HOST` 等），
   否则推荐页刷不出、识别全失败。
