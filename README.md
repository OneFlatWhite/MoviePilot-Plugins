## 插件列表

### 📺 缺集自动补齐（LackEpisodeAutoSub）

定时扫描 Emby 剧集库，对比 TMDB 找出缺集的剧，按**优先级策略 + 每日配额**自动挂 MP 订阅补齐；订完之后通过**下载验证回环**持续盯梢，形成完整闭环。

**核心能力**

- 🔍 **缺集扫描**：遍历 Emby 剧集库，与 TMDB 已播出分集比对，找出缺集
- 🎯 **优先级策略**：优先地区多选（大陆/港台/日韩/欧美）、动漫/纪录片优先、缺集数或评分排序——先补什么你说了算
- 🛡️ **风控三连**：每日配额（默认 200 部）、订阅间隔、连续失败熔断、单轮超时保护
- 🔄 **验证回环**：订阅后每天复查是否真入库，超 7 天未入库告警；qb 死任务检测（0 速度超 6 小时提醒）；下载目录磁盘告警
- 🧪 **调试模式**：默认开启，先只记录不真订，确认识别无误后再放量
- ⏰ **小白友好调度**：频率下拉 + 几点几分，不用懂 cron
- 🔌 **远程 API**：`GET /scan` 手动触发、`GET /status` 查状态（apikey 鉴权），可接企业微信

**工作流**

```
定时扫描 Emby 库 → 对比 TMDB 找缺集 → 过滤去重（已订阅/已处理/排除词）
→ 按优先级分层排队 → 按每日配额逐部订阅（MP 自动只补缺集）
→ 每天复查：入库核销 / 部分补齐继续等 / 超期告警
```

**使用前请阅读**：插件详情页底部的说明文字，或仓库内 [插件源码头部注释](plugins.v2/lackepisodeautosub/__init__.py)。

**要求**：MoviePilot V2、已配置 Emby 媒体服务器、Emby 剧集已刮削（有 TMDB ID）。
